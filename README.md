# 🎯 Digital Tools Marketplace

## 📌 Project Overview

Digital Tools Marketplace is a modern and responsive web application where users can explore and purchase premium digital tools such as design software, productivity apps, and development resources. The platform provides a clean UI, smooth user experience, and dynamic cart functionality to simulate a real-world buying system.

---

## 🚀 Technologies Used

* ⚛️ React.js
* 🎨 Tailwind CSS & DaisyUI
* 🧠 JavaScript (ES6+)
* 🔔 React Toastify
* 📦 JSON (for product data management)

---

## ✨ Key Features

1. 🛒 **Dynamic Cart System**
   Users can add products to the cart, remove them individually, and see real-time updates including total items and pricing.

2. 🔄 **Toggle View Functionality**
   Seamlessly switch between Products and Cart sections with interactive UI controls.

3. 🔔 **Interactive Notifications**
   Toast notifications provide instant feedback for actions like adding items, removing items, and checkout.

---

## 🌐 Live Experience

Explore digital tools, manage your cart, and enjoy a smooth, responsive interface across all devices.
